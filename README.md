Welcome to a little bit about -> HelpDesk

A responsive internal IT self-service portal built as my first independent frontend project after graduation. 
 
About the project:
 
HelpDesk is a fictional internal IT selfservice portal designed to make it easier for employees to find help with common IT problems. 
 
The idea is to create one place where employees can find help articles, check IT service status, report technical issues, view support tickets, report security concerns, and find the right way to contact IT support. 
  
Why am I building it?
 
After completing my studies, I wanted to revisit the fundamentals of frontend development by building something from scratch instead of only following tutorials.   
I also want to use HelpDesk as a continuous learning project. The first version will focus on structure, responsive design, and accessibility. 
 
Current status:
 
Work in progress :) 
 
HelpDesk is currently in the planning and design phase. 
 
I am defining the content, page structure, and user flows, while creating wireframes and UI designs in Figma before implementing the first version with HTML and CSS. 
 
Version 1: 
 
The first version will focus on the structure and responsive user interface of the portal. 
 
Planned pages include: 
 
- Home 
- Help Categories 
- Help Articles 
- My Tickets 
- Report an Issue 
- IT Status & News 
- Report a Security Incident 
 
Some elements, such as search, ticket submission, sign in, may initially be included as visual prototypes before becoming functional later on.
 
Version 1 will be built with:
 
- HTML5 
- CSS3 
- Flexbox 
- CSS Grid 
- Responsive design 
- Media queries 
 

Future development:
HelpDesk wil evolve as I continue developing my skills, and the project and future iterations may include:
 
- JavaScript and interactive functionality
- A modern frontend framework
- REST API intergration
- Backend development
- Database integration
