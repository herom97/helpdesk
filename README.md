# HelpDesk
 
A responsive internal IT self-service portal built as my first independent frontend project after graduation.
 
## About the Project
 
HelpDesk is a fictional internal IT self service portal designed to help employees quickly find answers to common IT related issues and requests.
 
The goal is to create a central place where employees can:
 
- Find help articles and guides
- Browse IT support categories
- Report technical issues and security concerns
- Check IT status and updates
- Access onboarding resources for new employees
 
## Why Am I Building It?
 
After completing my studies, I wanted to revisit and strengthen the fundamentals of web development by building something from scratch instead of only following tutorials.

For me, coding is not just about finishing a project.
 
It is about building with purpose, solving real problems, and creating solutions that help users accomplish meaningful tasks.
 
HelpDesk serves as both a portfolio project and a continuous learning project where I can apply new concepts as I progress.
